# Deep Learning Practicals

This repository contains six Deep Learning practicals implemented using Python, TensorFlow, Keras and Jupyter Notebook.

## Practical List

1. Feedforward Neural Network using MNIST
2. Feedforward Neural Network using CIFAR-10
3. Image Classification using CNN
4. Anomaly Detection using Autoencoder
5. Continuous Bag of Words (CBOW) Model
6. Object Detection using Transfer Learning

## Technologies Used

- Python
- TensorFlow and Keras
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
