Aim: To implement a Feedforward Neural Network using TensorFlow and Keras to classify images into 10 different categories using the CIFAR-10 dataset.

Short explanation: CIFAR-10 mein 10 types ki images hoti hain, jaise airplane, car, bird, cat, dog, etc. Feedforward Neural Network in images ko classify karna seekhta hai.


Expected output
1. CIFAR-10 sample images.
2. Training and validation accuracy/loss graphs.
3. Test accuracy.
4. Actual and predicted class names for 10 images.
Note: A basic feedforward network may achieve around 40–55% accuracy, depending on training settings. This is normal for CIFAR-10; CNNs are generally better at image classification.
