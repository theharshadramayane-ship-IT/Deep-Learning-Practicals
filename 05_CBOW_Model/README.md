Aim: To implement a CBOW model using a neural network to predict a target word from its surrounding context words.

Short explanation: CBOW model surrounding words ko input leta hai aur unke beech ka missing/target word predict karta hai.

Example:
- Sentence: I love deep learning
- Context words: I, deep
- Target word: love

Expected output
1. Vocabulary list.
2. Context words and predicted target word.
3. Training accuracy.
4. Training loss graph.
5. Learned word embeddings.
Note: This is a small demonstration corpus. Accuracy and predictions depend on the limited training sentences; it is not a general-purpose language model.
