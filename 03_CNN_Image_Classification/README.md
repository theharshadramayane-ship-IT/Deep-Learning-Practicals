1. Aim
To build an Image Classification model using Convolutional Neural Network (CNN) with TensorFlow and Keras, train it on the CIFAR-10 dataset and evaluate its classification performance.

2. Practical steps
Step	Task	Explanation
1	Import libraries	Import required packages
2	Load dataset	Load CIFAR-10 images
3	Preprocess images	Normalize image pixels
4	Define CNN architecture	Create convolution and pooling layers
5	Compile model	Set optimizer and loss
6	Train model	Train CNN using images
7	Evaluate model	Calculate test accuracy
8	Plot graphs	Display loss and accuracy
9	Predict images	Show actual vs predicted classes


6. Result
The CNN-based image classification model was successfully implemented using TensorFlow and Keras. The model was trained on CIFAR-10 and evaluated using test accuracy and loss.
